How It Works

This platform demonstrates a complete MLOps lifecycle: model training via MLflow, artifact storage in MinIO, live predictions through a FastAPI service, data drift monitoring with Evidently, and a user feedback loop that triggers retraining. Everything runs in Docker containers behind an Nginx reverse proxy.

What will happen

The pipeline will load the working dataset, split it into train/test sets, fit a Logistic Regression model with preprocessing (imputation, scaling, one-hot encoding), log parameters and metrics to MLflow, register the model in the MLflow Model Registry, and save a local fallback. A drift report is also generated after training.

Simulate Data Drift

Inject synthetic passengers with inverted survival patterns to demonstrate how drift detection works in an MLOps pipeline.

What will happen

The system will generate synthetic passenger records where survival rules are inverted (e.g., 3rd class passengers with high fares survive, 1st class passengers do not). These records are appended to the working dataset. Then Evidently generates a drift report comparing the corrupted data against the original training baseline. The model is NOT retrained automatically, so you can observe the drift before deciding what to do next.
